# Template de Artigo para Blog - Prof. Daniel Barral

## Como usar este template

### 1. Estrutura Obrigatória

Seu documento Word deve seguir EXATAMENTE esta estrutura:

```
Título: [Seu título aqui]
Autor: Prof. Daniel Barral
Data: DD/MM/AAAA
Tags: [Selecione as tags relevantes da lista abaixo, separadas por vírgula]
Resumo: [Breve resumo do artigo em 1-2 frases]

[LINHA EM BRANCO]

[INÍCIO DO CONTEÚDO DO ARTIGO]

...seu conteúdo aqui...

[FINAL DO CONTEÚDO]

---

Notas de Rodapé

¹ Primeira nota de rodapé aqui
² Segunda nota de rodapé aqui
³ Terceira nota de rodapé aqui

---

Referências Bibliográficas

SOBRENOME, Nome. Título da obra. Edição. Cidade: Editora, ano.

BRASIL. Lei nº X.XXX, de XX de XXXXX de XXXX. Descrição. Diário Oficial da União, Brasília, DF, XX XXX. XXXX.
```

### 3. Como usar Notas de Rodapé

No texto do artigo, use números sobrescritos:

**No Word:**
- Digite o texto normalmente
- Onde quiser a nota, insira o número sobrescrito (¹, ², ³, etc.)
- Ou use [1], [2], [3] que será convertido automaticamente

**Exemplos:**
```
"A Lei 14.133/2021¹ trouxe importantes inovações..."
"Conforme estabelecido pela doutrina²..."
"O entendimento jurisprudencial³ é pacífico..."
```

Ao final do documento, na seção "Notas de Rodapé", liste todas:

```
¹ Lei nº 14.133, de 1º de abril de 2021, estabelece normas gerais de licitação e contratação...
² DI PIETRO, Maria Sylvia Zanella. Direito Administrativo. 34. ed. São Paulo: Atlas, 2021, p. 456.
³ STJ, REsp 1.234.567/DF, Rel. Min. Fulano de Tal, 2ª Turma, j. 15/03/2023.
```

### 4. Formatação do Conteúdo

Use os recursos de formatação do Word normalmente:

#### Títulos e Subtítulos:
- **Título 1** (Heading 1) para seções principais
- **Título 2** (Heading 2) para subseções
- **Título 3** (Heading 3) para sub-subseções

#### Formatação de Texto:
- **Negrito** para destacar termos importantes
- *Itálico* para citações curtas ou ênfase
- Listas numeradas para passos ou sequências
- Listas com marcadores para itens não sequenciais

#### Citações:
Use o estilo "Citação" do Word para blocos de citação:

> "Texto da citação longa que será destacada visualmente no blog."

#### Tabelas:
Podem ser incluídas normalmente e serão convertidas.

### 5. Referências Bibliográficas (Formato ABNT)

Na seção "Referências Bibliográficas", siga o formato ABNT:

#### Livros:
```
SOBRENOME, Nome. Título da obra em negrito. Edição. Cidade: Editora, ano.
```

Exemplo:
```
DI PIETRO, Maria Sylvia Zanella. Direito Administrativo. 34. ed. São Paulo: Atlas, 2021.
```

#### Legislação:
```
BRASIL. Lei/Decreto nº X.XXX, de DD de MÊS de AAAA. Ementa resumida. Diário Oficial da União, Brasília, DF, DD MÊS AAAA. Seção X, p. XX.
```

Exemplo:
```
BRASIL. Lei nº 14.133, de 1º de abril de 2021. Estabelece normas gerais de licitação e contratação para as Administrações Públicas diretas, autárquicas e fundacionais da União, dos Estados, do Distrito Federal e dos Municípios. Diário Oficial da União, Brasília, DF, 1 abr. 2021.
```

#### Artigos:
```
SOBRENOME, Nome. Título do artigo. Nome da Revista, Local, v. X, n. X, p. XX-XX, mês ano.
```

Exemplo:
```
OLIVEIRA, Rafael Carvalho Rezende. As inovações da Lei 14.133/2021 em matéria de planejamento da contratação. Revista de Direito Administrativo, Rio de Janeiro, v. 280, n. 2, p. 45-78, mai./ago. 2021.
```

#### Jurisprudência:
```
ÓRGÃO. Tipo de Decisão nº XXX, Relator: Min./Des. Nome, Turma/Órgão julgador, Data de julgamento, Data de publicação.
```

Exemplo:
```
SUPERIOR TRIBUNAL DE JUSTIÇA. REsp 1.234.567/DF, Rel. Min. João Silva, 2ª Turma, j. 15/03/2023, DJe 20/03/2023.
```

### 6. Imagens (Opcional)

Se seu artigo contiver imagens:
- Insira normalmente no Word
- Use legendas descritivas
- Prefira imagens de alta qualidade
- Evite imagens muito pesadas (max 2MB cada)

### 7. Checklist Antes de Enviar

- [ ] Todos os campos obrigatórios estão preenchidos (Título, Autor, Data, Tags, Resumo)
- [ ] As tags foram selecionadas da lista fornecida
- [ ] O conteúdo está bem formatado com títulos e subtítulos
- [ ] As notas de rodapé estão numeradas corretamente
- [ ] As referências estão no formato ABNT
- [ ] O texto foi revisado (ortografia e gramática)
- [ ] Nomes de leis e termos jurídicos estão corretos
- [ ] O arquivo está salvo em formato .docx

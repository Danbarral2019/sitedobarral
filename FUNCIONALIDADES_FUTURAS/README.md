# 📦 Funcionalidades Futuras

Este diretório contém código de funcionalidades que podem ser implementadas no futuro.

## 📁 Estrutura

### `/analise-ia/`
Sistema completo de análise de documentos com IA usando Claude:
- Análise automática de documentos
- Geração de sumários
- Classificação em lote
- Extração de metadados

### `/export-pdf/`
Sistema de exportação de documentos em PDF com marca d'água personalizada.

## 🔄 Como Usar

Quando quiser implementar uma dessas funcionalidades:
1. Copie os arquivos da pasta correspondente
2. Siga as instruções no README.md de cada funcionalidade
3. Ajuste as rotas e imports conforme necessário
4. Teste completamente antes de usar em produção

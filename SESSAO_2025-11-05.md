## 🚀 Parte 2: Fix Crítico do Scraper DOU

### Contexto
Scraper DOU configurado para rodar diariamente às 10h UTC (7h BRT) via Vercel Cron, mas retornando **500 Internal Server Error** em produção.

### Diagnóstico Detalhado

#### Fase 1: Investigação Inicial
1. **Hipótese 1:** Timeout (100 documentos = muito tempo)
   - ❌ Reduzir limite para 20 não resolveu

2. **Hipótese 2:** Missing dependencies
   - ✅ jsdom instalado como production dep

3. **Logging detalhado adicionado:**
   ```typescript
   console.log('[Cron DOU] DEBUG - Etapa 1/7: Validando secret...');
   console.log('[Cron DOU] DEBUG - Etapa 2/7: Parsing params...');
   // ... até Etapa 7/7
   ```

#### Fase 2: Descoberta do Problema Real
**Log do Vercel capturado:**
```
Error: Failed to load external module jsdom:
Error [ERR_REQUIRE_ESM]: require() of ES Module
/var/task/node_modules/jsdom/node_modules/parse5/dist/index.js
not supported
```

**Causa Raiz:**
- `jsdom` usa `parse5` como dependência
- `parse5` é módulo ESM puro (ES Module)
- Vercel Turbopack tenta fazer `require()` de módulo ESM
- ❌ Incompatível com ambiente serverless

### Solução Implementada

#### Tentativa 1: Substituir jsdom → cheerio (FALHOU)
```bash
npm install cheerio  # Instalou v1.1.2
```
**Resultado:** ❌ Cheerio 1.x também é ESM-only!

#### Tentativa 2: Downgrade cheerio → 0.22.0 (SUCESSO ✅)
```bash
npm install cheerio@0.22.0
npm uninstall jsdom  # Removeu 38 pacotes!
```

**Mudanças no código (`lib/dou-api.ts`):**
```typescript
// ANTES
import { JSDOM } from 'jsdom';
const dom = new JSDOM(html);
const document = dom.window.document;
const lastPageBtn = document.querySelector('button#lastPage');

// DEPOIS
import * as cheerio from 'cheerio';
const $ = cheerio.load(html);
const lastPageBtn = $('button#lastPage');
```

**Benefícios:**
- ✅ CommonJS puro (compatível com Vercel)
- ✅ Mais leve (~1.5MB menos no bundle)
- ✅ API similar, poucas mudanças
- ✅ Mesma funcionalidade

## 📝 Notas Técnicas

### Por que cheerio 0.22.0 funciona?
1. **CommonJS puro:** Usa `require()` tradicional
2. **Sem dependências ESM:** Todas as deps são CommonJS
3. **Vercel-friendly:** Totalmente compatível com serverless
4. **Estável:** Versão madura, amplamente testada

### Comparação jsdom vs cheerio

| Aspecto | jsdom | cheerio 0.22.0 |
|---------|-------|----------------|
| Tipo módulo | ESM (parse5) | CommonJS |
| Bundle size | ~3.5MB | ~2MB |
| Vercel compat | ❌ | ✅ |
| API | DOM completo | jQuery-like |
| Performance | Mais lento | Mais rápido |
| Caso de uso | Testes e2e | Web scraping |

### Lições Aprendidas
1. **ESM no serverless:** Cuidado com dependências ESM em Vercel
2. **Logs são essenciais:** Logging detalhado salvou tempo
3. **Testes incrementais:** Testar com poucos docs primeiro
4. **Downgrade funciona:** Nem sempre a versão mais nova é melhor
5. **Secrets no git:** GitHub bloqueia (push protection funcionou)
